# 調査メモの使い方

対応する記事：「AIの調べものを、出典つきの調査メモにして記事や判断に使う手順【テンプレ付き】」

| ファイル | 中身 |
|---|---|
| 調査依頼.md | 調べものを頼む依頼文（決めること、資料の優先順位、反例、未確認の書き方、返してほしい形）と記入例 |
| 調査メモ.md | 主張ごとに、出典URL・確認日・一次か二次か・確認した範囲・引用・未確認を残すメモ（主張1つが1ブロック、記入例3件つき） |
| 公式照合.md | 原稿の技術的な記述を、出す日の公式文書と照らしてもらう依頼文 |
| link_check.py | 原稿の中のURLを抜き出して、開けるかどうかを一覧にするスクリプト |

## 流れ

1. 調査依頼.md の【】を書き換えて、AIに渡す
2. 返ってきた結果を、調べもの1件につき1ファイルの 調査メモ.md として保存する
3. 数字・固有名詞・日付が入った主張から3件を選び、自分で出典を開き直す
4. 原稿を書いたら、公式照合.md でAIに公式文書と照らしてもらう
5. 出す前に link_check.py で原稿のURLを確かめる

## link_check.py

Python 3 の標準ライブラリだけで動くので、インストールするものはない
Windowsでは `python3` を `py -3` に置き換える

```sh
python3 link_check.py 原稿.md
python3 link_check.py 原稿.md --timeout 10 --ignore example.com
python3 link_check.py 原稿.md -o link_check_結果.md
```

| オプション | 意味 |
|---|---|
| `--timeout` | 1回の問い合わせを待つ秒数（既定10） |
| `--wait` | 問い合わせの間をあける秒数（既定0.3） |
| `--ignore` | この文字を含むURLは確かめない（何回でも指定できる） |
| `-o` | 画面に出したのと同じ一覧をファイルに書き出す（同じ名前のファイルがすでにあるときは書き出さずに止まる） |

判定の読み方

| 判定 | 意味 | すること |
|---|---|---|
| 開けた | 応答が200番台 | 中身が主張と合うかは、開いて読んで確かめる |
| 転送あり | 別のURLへ転送されたあと200番台 | 記事には着いたURLを貼り直す |
| 見つからない | 404・410 | 出典を探し直し、見つからなければ主張ごと外す |
| 拒否 | 401・403 | ブラウザで開いて確かめる（プログラムからの取得だけを断るページもある） |
| 回数制限 | 429 | 時間をおいて実行し直す |
| 相手側のエラー | 500番台 | 時間をおいて実行し直す |
| 転送が多すぎる | 5回を超える転送 | ブラウザで開いて確かめる |
| 開けない | ドメインがない、時間切れ、証明書のエラーなど | URLの打ち間違いを確かめる |

終了コード

- 0：すべて開けた（転送ありを含む）
- 1：開けない・見つからない・拒否などのURLがある
- 2：使い方の誤り（入力ファイルがない、フォルダーや画像を渡した、URLが1件もない、書き出し先がすでにある、`--timeout` が0以下など）

### 動作を確かめた範囲

- macOS 26.6.2 の Python 3.14.6 と Python 3.9.6 で、2026-10-18 に確認した
- 手元の試験用サーバーで確かめたこと：200、HEADを断るページ（GETで取り直して200）、301・302・307・308の転送、転送の繰り返し、403、404、500、時間切れ
- 外のサイトで確かめたこと：実在するページ、存在しないページ、存在しないドメイン、前の場所から308で転送されるページ
- ファイルで確かめたこと：BOM付き・改行がCRLFのファイルを読める
- 終了コード2で止まることを確かめたもの：入力ファイルがない、フォルダーを渡した、画像を渡した、URLがない、`--timeout 0`、`--timeout abc`、`--wait -1`、書き出し先がすでにある（中身が変わらないことも確認）、書き出し先のフォルダーがない
- Windowsの実機では確かめていない
- 同じページでも、Pythonの版によって403になることがあった（noteのヘルプのページが、3.14では開け、3.9では毎回403）
- 拒否と出たら、ブラウザで開いて確かめる

## 注意

- link_check.py は、原稿に書いてあるURLすべてに問い合わせを送るので、社内のページや、トークン入りのURLを含む原稿には使わない
- 「開けた」は、そのページに主張が書いてあることの確認にはならない
- 調査メモと結果のファイルには、自分が何を調べたかが残るので、公開するフォルダーに置くかどうかは自分で決める
- 有料部分やログインが必要なページは、調べものの対象にしない
