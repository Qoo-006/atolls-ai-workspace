# 事故メモ

外部サービスで意図しない操作が起きたとき、または起きかけたときに書く
書く前に、まずAIの作業を止める

## 手順

1. AIの作業を止める（実行中なら中断して、続きをさせない）
2. 何が外に出たかを、サービスの画面で確かめる（AIの報告だけで判断しない）
3. 取り消せるものを取り消す（投稿の削除、予約の取り消し、送ったメールなら訂正の連絡を自分で書く）
4. このメモを書く
5. 線引き表と指示ファイルと設定の、どこが足りなかったかを直す

## 記録

- 日時:
- サービスと名義:
- 起きたこと:
- 外に出たもの（誰に、何が届いたか）:
- 取り消したこと:
- ずれた場所（段階・名義・依頼の範囲のどれか）:
- 次から（線引き表・指示ファイル・設定のどこを直したか）:

## 記入例（外には何も出なかった例）

- 日時: 2026-10-08
- サービスと名義: X、発信用のアカウント
- 起きたこと: 文を入れた投稿画面をURLで開き、閉じたら下書きに残らなかった
- 外に出たもの: なし
- 取り消したこと: なし
- ずれた場所: 段階（その開き方の投稿画面は、閉じると下書きにならずに消える）
- 次から: 下書きは別の投稿画面から保存して、下書きの一覧に出たかを見てから「保存した」と報告させる
