# ブラウザ操作の依頼文

AIにブラウザで外部サービスを触ってもらうときに渡す文
{ } の中を書き換えてから渡す

```text
ブラウザで次の作業をお願いします

作業: {やること（例: noteの記事に本文を入れて下書き保存する）}
使うアカウント: {画面に出る名義（例: 発信用のアカウント名）}
押さないボタン: {例: 公開に進む、投稿する}

進め方:
1. ブラウザを開いたら、何か操作する前に、画面に出ているログイン名義（アカウント名かメールアドレス）を報告して、私の返事を待つ
2. 名義が「使うアカウント」と違う、または画面で確かめられないときは、何も操作せずにそのことを報告する
3. 途中で接続が切れたり、別のウィンドウやタブに移ったりしたら、続きを始める前に名義を確かめ直して報告する
4. 「押さないボタン」は押さない、その手前まで進めたら、画面の状態を報告して止まる
5. 保存したときは、下書きの一覧を開くかページを読み込み直して、保存したものが残っているかを確かめる
6. 安全の判定や権限の確認で止められたら、別の方法を試さずに、止まった操作をそのまま報告する

最後に報告すること:
- 操作したアカウントの名義
- やったことと、押していないボタン
- 保存を確かめた画面（どこを見て、何が残っていたか）
- 確かめられなかったこと
```
