# 操作の線引きキットの使い方

対応する記事：「AIに外部サービスを触らせる前に、線引き表と権限設定を作る手順【テンプレ付き】」

AIにメール・SNS・ブラウザなど外部サービスを触らせる前に、どこで止めて自分が押すかを1枚にまとめ、指示ファイルと設定ファイルに落とすための一式。

| ファイル | 中身 | 置く場所の例 |
|---|---|---|
| 線引き表.md | サービス×操作ごとに、AIが止まる段階・本人が押すもの・名義を1件ずつ書く。記入例7件と空の型入り | 作業フォルダーの docs/ など |
| 指示ファイルに足す文.md | CLAUDE.md（Claude Code）か AGENTS.md（Codex）に足す文 | 各指示ファイルの末尾 |
| claude_settings_例.json | Claude Code の permissions（allow・ask・deny）の例 | ~/.claude/settings.json などに中身を足す |
| codex_config_例.toml | Codex の sandbox_mode・approval_policy の例 | ~/.codex/config.toml に足す |
| readonly.config.toml | Codex の読むだけ用プロファイル | ~/.codex/readonly.config.toml |
| ブラウザ操作の依頼文.md | ブラウザ操作を頼むときに渡す文（名義の確認と、押さないボタンの指定） | 頼むたびに書き換えて使う |
| 事故メモ.md | 意図しない操作が起きた・起きかけたときの手順と記録欄 | 線引き表と同じ場所 |

## 進め方

1. 線引き表.md の記入例を消し、自分がAIに触らせているサービスと操作を1件ずつ書く
2. 指示ファイルに足す文.md の text 部分を、CLAUDE.md か AGENTS.md の末尾に足す（線引き表のパスを書き換える）
3. claude_settings_例.json の mail を、自分が登録したMCP（AIを外部サービスにつなぐ仕組み）サーバーの名前に置き換えてから、今の settings.json の permissions に足す（ファイルごと置き換えない）
4. codex_config_例.toml の内容を ~/.codex/config.toml に足す。調べもの用に readonly.config.toml を置くと `codex --profile readonly` で読むだけの状態で起動できる
5. ブラウザ操作を頼むときは、ブラウザ操作の依頼文.md を書き換えて渡す

## 読み込めるかの確かめ方

```sh
python3 -m json.tool ~/.claude/settings.json
```

JSONとして読めないと、行と位置が出て終了コード1で止まる。`//` のコメントと、最後の項目の後ろのカンマはJSONでは書けない。
Claude Code の中では `/permissions` で規則とその出どころのファイル、`/status` で設定ファイルが読み込まれたかを確かめる。

Codex は、設定ファイルに使えない値（例：approval_policy = "untrusted"）があると、起動時にエラーで止まる。

Windowsでは `python3` を `py -3` に置き換える。

## 動作を確かめた範囲

- claude_settings_例.json：macOS・Python 3.14.6 の `python3 -m json.tool` でJSONとして読めることを確認。Claude Code 本体に読み込ませての確認はしていない
- codex_config_例.toml・readonly.config.toml：macOS・Python 3.14.6 の tomllib で読めること、Codex CLI（ターミナルで動かす版）0.162.1 に試験用のフォルダー（CODEX_HOME）で読み込ませてエラーなく起動することを確認
- 使えない値（sandbox_mode = "bogus"、approval_policy = "untrusted"）は、Codex CLI 0.162.1 が終了コード1で止まることを確認
- Windows は未確認

## 気をつけること

- 設定で止められるのは、道具やコマンド、ファイル、ドメインの単位まで。ブラウザで「どのボタンを押すか」は設定では分けられないので、依頼文と線引き表で止める
- settings.json・config.toml・線引き表に、トークンやパスワードを書かない
