# 整理の依頼文

inbox にたまった会話ログを、トピックごとのまとめページへ振り分けるときに、Claude Code か Codex に渡す文です。
`AIログ` は保管庫（Obsidian のフォルダー）の中の保存先の名前に合わせて書き換えてください。

整理する会話そのものが inbox に増えないように、Claude Code は記録を止めて起動します。

```sh
SAVE_LOG_OFF=1 claude
```

```text
AIログ/inbox にある会話ログを、トピックごとのまとめページに振り分けてください
まとめページは AIログ/topics/ にあります

進め方:
1. inbox のファイルを、ファイル名の日付が古い順に最大10件だけ読む
2. 次のファイルは振り分けずに、最後の報告に回す
   - 空のログ: 自分の発言が挨拶や確認だけで、作業の中身がない
   - 重複: frontmatter の session_id が同じファイルが2つ以上ある（updated が新しい方だけを振り分ける）
   - 迷うログ: どのトピックか1つに決められない
3. 残りのログごとに、AIログ/topics/ にあるまとめページから、トピックを1つ選ぶ
   どれにも合わなければ、新しいトピック名の案を出して、作る前に私に聞く
4. ログを AIログ/archive/年-月/ に移す（例: ファイル名が 2026-10-21 で始まるなら AIログ/archive/2026-10/）
5. まとめページの「## 会話」の見出しのすぐ下に、次の形で1行足す
   - 2026-10-21 [[AIログ/archive/2026-10/2026-10-21_1a2b3c4d]] 何をしたかの要約（40字以内）
6. ログの中で私が「これで決定」「こうする」のように決めたことがあれば、まとめページの「## 決めたこと」にも同じ形で1行足す
7. ログの frontmatter の topic: にトピック名を書く

守ること:
- ログの本文を書き換えない、消さない（書き換えてよいのは frontmatter の topic: だけ）
- 要約にログに無いことを足さない（何も決まっていなければ「相談のみ」と書く）
- リンクは保管庫のいちばん上からのフォルダーを含めて書く
- 2で回したファイルは inbox に残す
- 人の名前、会社や取引先の名前、連絡先、パスワードやトークンらしい文字列は、まとめページに書かない
- 最後に、振り分けた件数、トピックごとの件数、inbox に残したファイル（ファイル名と理由）を報告する
```

## メモ

- 10件ずつにしているのは、1回に読む量を抑えて、要約の取り違えを見つけやすくするためです。慣れたら増やしてかまいません。
- まとめページが1枚も無いときは、まとめページのテンプレ.md を AIログ/topics/ に置いて、名前をトピック名に変えてから始めます。
