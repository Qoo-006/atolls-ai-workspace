# 会話ログを残してまとめるキットの使い方

対応する記事：「Claude Codeの会話を1会話1ファイルで残して、トピックごとにまとめる手順【テンプレ付き】」

| ファイル | 中身 |
|---|---|
| save_log.py | Claude Code の会話ログ（.jsonl）を読み、1会話1ファイルの Markdown に書き出すスクリプト |
| settings例.md | `~/.claude/settings.json` に足すフック（Stop・SessionEnd）の書き方と、既存の設定に足すときの注意 |
| 整理の依頼文.md | inbox にたまったログを、トピックごとのまとめページへ振り分けてもらう依頼文 |
| まとめページのテンプレ.md | トピックごとのまとめページの形（記入例入り） |

## 動作を確かめた範囲

- macOS、Python 3.9.6 と 3.14.6（標準ライブラリだけを使用）
- Claude Code から渡される入力を真似たサンプル（会話ログ .jsonl とフックの標準入力 JSON）で、40項目を確かめた
  - 新しく作る、同じ会話は同じファイルを更新する、archive に移した後も同じファイルを更新する、整理で書いた topic を残す
  - ツールの結果・AIの考え中の内容・サブエージェントの会話・自動の補足を除く、最後の返事を補う
  - SAVE_LOG_OFF で止まる、SAVE_LOG_DIR で保存先を指定できる
  - よそのファイルを上書きしない、保存先や会話ログの指定が誤っているときは終了コード1で止まる
  - 別々の会話を同時に保存しても混ざらない、同じ会話を同時に保存しても1ファイルのまま
  - 約35MB・2万行の会話ログで、保存にかかった時間は1〜2.5秒
- 実際の Claude Code のフックに登録して、自動で動くところは確かめていない（確かめたのは、上のサンプル入力と、`--transcript` を付けて手で動かす形まで）
- Windows は確かめていない（`python3` は `py -3` に置き換えが必要かもしれない）
- 会話ログ（.jsonl）の中身の形式は、公式の文書に説明が見つけられなかった。手元のログを見て読み方を決めているので、Claude Code の更新で形式が変わると、正しく書き出せなくなる可能性がある

## 置き場所の例

```
~/ai-tools/save_log.py                 ← スクリプト（保管庫の外に置く）
（Obsidian の保管庫）/AIログ/
    inbox/      ← save_log.py が書く（整理待ち）
    archive/    ← 整理が終わったログ（年-月ごと）
    topics/     ← トピックごとのまとめページ
```

`--out` には `AIログ` フォルダーを指定する。inbox は無ければ自動で作る。`AIログ` フォルダー自体は先に自分で作っておく（打ち間違えた場所に書かないように、無いフォルダーには書かない）。

## コマンド

```sh
# まず手で1件だけ書き出して、中身を確かめる
python3 ~/ai-tools/save_log.py --out "$HOME/Documents/MyVault/AIログ" --transcript ~/.claude/projects/<プロジェクトのフォルダー>/<会話ID>.jsonl

# 残っている会話ログ（既定では30日分）をまとめて書き出す
for f in ~/.claude/projects/*/*.jsonl; do python3 ~/ai-tools/save_log.py --out "$HOME/Documents/MyVault/AIログ" --transcript "$f"; done

# 記録を止めて Claude Code を起動する（整理の会話など）
SAVE_LOG_OFF=1 claude

# 自動で入った補足や通知も「自動」として残したいとき
python3 ~/ai-tools/save_log.py --out "$HOME/Documents/MyVault/AIログ" --keep-auto --transcript <会話ログ.jsonl>
```

フックへの登録は settings例.md を見る。

## 終了コード

- 0: 保存した、保存する自分の発言が無かった、SAVE_LOG_OFF で止めた
- 1: 保存先や会話ログの指定が誤っている、標準入力が読めない、上書きになる名前しか無い
- 2 は使わない（Stop フックで2を返すと、Claude Code が返事を終われなくなるため）

## 注意

- 書き出したログには、自分が貼り付けた文章もそのまま入る。公開するフォルダーや Git の管理に入れない。
- 保管庫をクラウドで同期しているなら、ログも同期先に上がる。そうしたくない会話は SAVE_LOG_OFF=1 を付けて起動する。
- 公式の文書によると、Claude Code の会話ログ（.jsonl）は既定で30日たつと自動で消える。このスクリプトで書き出した Markdown は消えない。
