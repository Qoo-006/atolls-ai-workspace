# ダメ出し台帳の使い方

対応する記事：「AIへのダメ出しを台帳にして、作る前に読ませる手順【テンプレ付き】」

| ファイル | 中身 |
|---|---|
| criteria.md | 台帳のテンプレ。記入例3件入り |
| criteria.py | brief・lint・record・unused の4つの使い方がある道具 |
| extract_my_messages.py | Claude Codeの会話ログから自分の発言だけを書き出す |
| 抽出プロンプト.md | 書き出した発言から台帳の下書きを作らせる依頼文 |

Python 3（標準ライブラリだけ）で動く。

```sh
python3 extract_my_messages.py ~/.claude/projects/<プロジェクトのフォルダー> -o my_messages.md --since 2026-09-01
python3 criteria.py brief criteria.md --type note
python3 criteria.py lint criteria.md 原稿.md --type note --log hits.tsv
python3 criteria.py record criteria.md JP-001 --note "説明なし" --log hits.tsv
python3 criteria.py unused criteria.md --log hits.tsv --days 90
```

## 終了コード

| スクリプト | 0 | 1 | 2 |
|---|---|---|---|
| criteria.py lint | 該当なし | 該当あり | 台帳・原稿が読めない、検出の正規表現が壊れている（検査していない） |
| criteria.py brief・record・unused | 成功 | ― | 台帳が読めない、台帳に無いIDを指定した |
| extract_my_messages.py | 書き出した | 発言が0件（ファイルは作らない） | フォルダーが無い・フォルダーでない・.jsonl が無い・日付の形が違う・出力先がすでにある |

機械で見る基準が1件も当たらないとき、lint は 0 で終わるが「合格の意味にならない」と注意を出す。

## 確かめた範囲

- 2026-10-18、macOS 26・Python 3.14 で、作った試験用のデータを使い、上の表の各場合を実行して確かめた
- Windows と、Claude Code 以外のログの形式では試していない。Windowsでは `python3` を `py -3` に置き換えて動かす想定
- 会話ログの保存場所は公式文書に書かれているが、1行ごとの中身の形の説明は見つけられなかった。Claude Code の更新で形が変わると抜き出せなくなることがあるので、書き出した中身は一度目で確かめる

## 気をつけること

my_messages.md と hits.tsv には自分の会話の中身が入る。公開するフォルダーやGitの管理に入れない。
