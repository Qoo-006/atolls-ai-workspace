# テンプレート集

AIとの作業で使う台帳・依頼文・設定例・小さなスクリプトを、テーマごとのフォルダーにまとめています。KnowBrain本体（`scripts/brain.py`）とは独立しているので、必要なフォルダーだけを取り出して使えます。ファイルは誰でも無料で使えます。

| フォルダー | 中身 |
|---|---|
| `01_ダメ出し台帳/` | AIへの指摘を基準として残す台帳と、作業の前に当たる基準を出す `criteria.py` |
| `02_文体ルール/` | 自分の文体を書き出すプロファイルと、媒体ごとに原稿を検査する `style_check.py` |
| `03_会話ログ/` | Claude Codeの会話を1会話1ファイルのMarkdownに書き出す `save_log.py` と、整理の依頼文 |
| `04_調査メモ/` | 調べものの依頼文、主張ごとに出典を残す調査メモ、原稿のURLを確かめる `link_check.py` |
| `05_操作の線引き/` | AIに任せる操作の線引き表と、Claude Code・Codexの権限設定の例 |
| `06_並列作業/` | 並行作業の依頼書・受け入れ確認表と、変更範囲を確かめる `check_scope.py` |
| `07_消費の実測/` | Claude Codeの会話ログから使用量を集計する `usage_report.py` と、起動時に読むものの棚卸し表 |

## 使う前に

各フォルダーの `使い方.md` に、コマンド、終了コード、動作を確かめた範囲を書いています。スクリプトはPythonの標準ライブラリだけで動きます。動作はmacOSで確かめていて、Windowsでは確かめていません。

スクリプトと設定例は、中身を読んでから自分の環境で実行してください。設定ファイルは丸ごと置き換えず、バックアップを取ってから必要な行を足します。会話ログや台帳には自分の発言がそのまま入るので、出力したファイルを公開する場所に置かないでください。

Claude CodeやCodexの設定の書き方は、各ツールの更新で変わることがあります。動かないときは、それぞれの公式の説明と見比べてください。
