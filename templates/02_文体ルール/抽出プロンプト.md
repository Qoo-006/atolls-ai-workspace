# 過去の文章から文体プロファイルの下書きを作らせる依頼文

作業用のフォルダーに、次の4つを置いてから、Claude CodeかCodexをそのフォルダーで起動して、下の文を渡す。

- samples/ … 自分で書いた文章を3〜5本（ファイル名の先頭を媒体名にする。例: note_01.md、x_01.txt）
- feedback.md … AIの下書きに自分が言ったダメ出しを1行ずつ（日付・場面・自分の言葉）
- 文体プロファイル.md … このキットのテンプレ（記入例は消しておく）
- style_check.py … この段階では使わない

```text
samples/ に、私が自分で書いた文章を入れてあります
ファイル名の先頭が媒体名です（例: note_01.md、x_01.txt、linkedin_01.txt）
feedback.md には、私がAIの下書きに言ったダメ出しを1行ずつ書いてあります

この2つから、私の文体プロファイルの下書きを作ってください
見出しは 文体プロファイル.md に合わせます

進め方:
1. samples/ の文章を全部読み、一人称、口調、文末、区切り方、文の長さ、よく使う言い回しを拾う
2. 拾った特徴ごとに、見本から原文のまま短く引用し、ファイル名を添える
3. 2本以上に出てくる特徴を先に書き、1本にしか出てこない特徴には「1本だけ」と書く
4. 媒体で違う特徴は「媒体ごとの違い」に分ける（見本が1つの媒体だけなら空欄のままにする）
5. feedback.md のダメ出しは「使わない言い回し」に入れ、日付と私の言葉を根拠に書く
6. 機械で見られそうな特徴（記号、決まった言い回し、文末の形、文の長さ）は、最後に「規則の候補」として箇条書きにする

守ること:
- 見本とダメ出しにない特徴を作らない
- 文章の一般的なコツや、よく言われる禁止語を足さない
- 引用は見本にある文字のまま書き、言い換えない
- 「## 規則：」の節は書かない（機械で見る規則は私が決める）
- 判断できなかった項目は空欄にして、最後にまとめて報告する
- 下書きは 文体プロファイル_下書き.md に新しく保存する（同じ名前のファイルがあれば保存せずに知らせる）
- samples/、feedback.md、文体プロファイル.md は書き換えない
```
