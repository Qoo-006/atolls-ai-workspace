# 消費の実測キットの使い方

対応する記事：「Claude Codeの消費を自分の会話ログで測って、毎回の読み込みを減らす手順【集計スクリプト付き】」

| ファイル | 中身 |
|---|---|
| usage_report.py | 会話ログ（.jsonl）から、会話ごとの消費・文脈の大きさ・起動時の重さ・上限に当たった日時を集計する |
| 棚卸し表.md | 起動時に読み込むファイルを書き出して、残す・paths:に移す・スキルに移す・消すを決める表 |
| paths_例.md | ルールに paths: を付ける書き方と、付けるときに気をつけること |
| CLAUDE.md追記例.md | 参照先の表、要約で残すもの、上限が近いときの動き方を CLAUDE.md に足す例 |
| 引継ぎメモ.md | 上限の手前で書かせる引継ぎメモの型と依頼文 |

## 動作を確かめた範囲

- 2026-10-18 に macOS 26.6・Python 3.14.6 と Python 3.9.6 で、試験用の架空のログと実際の会話ログで実行して確かめた
- Windows では実行していない（未確認）。`python3` を `py -3` に置き換えて使う想定で書いている
- Claude Code のログの形式は版によって変わることがある。集計の結果が明らかにおかしいとき（会話が0本、応答の数が極端に少ない など）は、そのまま信じずに `/usage` の表示と見比べる

## 実行のしかた

```sh
python3 usage_report.py
python3 usage_report.py --since 2026-10-01 --until 2026-10-07
python3 usage_report.py --big 300000 --top 20
python3 usage_report.py --history
python3 usage_report.py --csv sessions.csv
python3 usage_report.py --hide-project
```

- 引数を省くと `~/.claude/projects/` の下を全部読む。特定のプロジェクトのフォルダーや、1つの .jsonl だけを指定してもよい
- `--since` `--until` は日付（YYYY-MM-DD）。直した日の前と後を同じ日数で比べるときに使う
- `--big` は「文脈が大きい会話」の境目（既定は50万トークン）
- `--read-weight` はキャッシュ読み込みの重み（既定0.1）。Claude Opus 5.5 と Sonnet 5.5 の公式の比率は0.05なので、ほとんどがこの2つなら `--read-weight 0.05` にする。比べるときは前後で同じ値を使う
- `--history` は `~/.claude/history.jsonl` から、自分が打った指示の数を月ごとに数える（/で始まるコマンドは除く）
- `--csv` は会話ごとの数字を表計算ソフトで見るためのファイル。同じ名前のファイルがあると何もせずに止まる
- `--hide-project` はプロジェクトのフォルダー名を伏せる。画面を人に見せるときに付ける

終了コードは、0が集計できた、1が対象の記録が1件もない、2が入力や設定の誤り（存在しないパス、.jsonl 以外のファイル、日付の書き方の誤り、同じ名前のCSVがある など）。

## 数え方

- AIの返事1回ごとの `message.usage` を足す。同じ返事が複数行に記録されるので、`message.id` で1回だけ数える
- 文脈の大きさは、入力・キャッシュ書き込み・キャッシュ読み込みの合計（出力は含めない）。ステータスラインの使用率と同じ数え方
- 重み付きの合計は、API（開発者向けの従量課金での利用）の単価の比率（入力1、キャッシュ書き込み5分1.25・1時間2、キャッシュ読み込み0.1、出力5）で入力に換算したもの。会話どうしを比べる物差しで、プランの上限の計算式そのものではない
- サブエージェントの記録は、呼び出した会話の分として足す
- 上限に当たった日時は、エラーとして記録された行から取る。同じ分に何回出ても1回と数える

## このログに入らないもの

- claude.ai のWebやスマホアプリでの会話、定期実行（Routines）、別の端末での利用
- Codex など、Claude Code 以外の道具
- 自動削除で消えたログ（既定では30日より古いものは消える。延ばすなら settings.json の `cleanupPeriodDays`）

## 扱いの注意

集計結果とCSVには会話のIDとプロジェクトのフォルダー名が入る。会話の本文は出さないが、公開するフォルダーやGitの管理には入れない。
