# 起動時に読み込むものの棚卸し表

Claude Codeを、ふだん一番よく使うフォルダーで起動してから埋める。

1. 起動した直後に `/context` を実行する（項目が畳まれていたら `/context all`）
2. 「Memory files」に出たファイルを、下の表に1行ずつ写す（トークン数も写す）
3. 行数は `wc -l <ファイル>`（Windowsは PowerShell で `(Get-Content <ファイル>).Count`）で数える
4. `.claude/rules/` の中で、先頭に `paths:` があるものは「条件付き」、ないものは「毎回」と書く
5. 最後の3列は、下の「決め方」を見ながら自分で埋める

```markdown
| ファイル | 行数 | トークン | いまの読み込み | 要る作業 | paths:にできるか | 移す先 |
|---|---|---|---|---|---|---|
| ~/.claude/CLAUDE.md |  |  | 毎回 |  |  |  |
| ./CLAUDE.md |  |  | 毎回 |  |  |  |
| ./.claude/rules/ |  |  |  |  |  |  |
| 自動メモリの MEMORY.md |  |  | 毎回（先頭200行か25KBまで） |  |  |  |
|  |  |  |  |  |  |  |
| 合計 |  |  |  |  |  |  |
```

## 記入例（架空の数字）

```text
| ファイル | 行数 | トークン | いまの読み込み | 要る作業 | paths:にできるか | 移す先 |
|---|---|---|---|---|---|---|
| ~/.claude/CLAUDE.md | 310 | 9,800 | 毎回 | 全部 | できない | 残す（禁止事項と参照先の表だけにして200行未満へ） |
| ./.claude/rules/git.md | 85 | 1,900 | 毎回 | コミットするとき | できる | paths: に .gitignore と自分自身 |
| ./.claude/rules/deploy.md | 140 | 3,300 | 毎回 | 公開作業のとき | できる | paths: に scripts/deploy/** |
| ./.claude/rules/report-format.md | 220 | 5,100 | 毎回 | 報告書を書くとき | 対象のファイルが決まらない | スキルに移す |
| ./.claude/rules/old-project.md | 60 | 1,200 | 毎回 | もう使っていない | - | 消す（ゴミ箱へ） |
```

## 決め方

- 毎回読むまま残す：どの作業でも破ってはいけないこと（送信や削除の前に確認する、秘密を書かない など）と、短い共通の決まり
- paths: に移す：特定のファイルやフォルダーを触るときだけ要るもの
- スキルに移す：対象のファイルが決まらない手順書（呼んだときだけ読み込まれる）
- 消す：もう使っていないもの、別のファイルと同じことを書いているもの
- CLAUDE.md の中で `@ファイル` で取り込んでいるものも起動時に読み込まれる。取り込みにしても量は減らない
