# 触るファイルを洗い出すプロンプト

順番表を書く前に、仕事ごとに触りそうなファイルをAIに挙げてもらうための依頼文。
main を開いたフォルダー（リポジトリ＝コードと変更の記録をまとめた場所の本体）で、Claude Code か Codex を起動して渡す。ファイルは読むだけで、変更もコミット（変更をgitに記録すること）もさせない。

```text
これから、次の仕事を同時に進めたい
まだ何も変えないで、ファイルを読むだけで答えて

仕事:
1. （仕事の名前と、やりたいこと）
2. （仕事の名前と、やりたいこと）
3. （仕事の名前と、やりたいこと）

やってほしいこと:
- 仕事ごとに、変更しそうなファイルを、リポジトリの一番上からの相対パスで挙げる
- それぞれのファイルについて、確かに変えるのか、たぶん変えるのかを分けて書く
- 新しく作りそうなファイルも挙げる
- 2つ以上の仕事に出てくるファイルを、最後にまとめて挙げる

守ること:
- ファイルの作成・変更・コミット・ブランチの作成をしない
- 中身を読んでいないファイルを挙げるときは「推測」と書く
- 答えは仕事ごとの表にして、順番表の「触るファイル」の欄にそのまま写せる形にする
```
