# 同じファイルを触る仕事の順番表

同時にAIへ頼みたい仕事が2つ以上あるときに、worktree を作る前に1枚書く。
作業場所を分けても、同じファイルを2つの仕事が変えると main に統合するときに競合する。
だから、同じファイルを触る仕事同士は同時に走らせず、先に統合する方を決める。

## 決め方

1. 同時に頼みたい仕事を書き出す
2. 仕事ごとに、触りそうなファイルを書く（分からなければ 洗い出しプロンプト.md でAIに聞く）
3. 2つ以上の仕事に出てくるファイルを「重なり」に書く
4. 重なりがある仕事同士は同じ「順」にしない。先に統合する方を小さい番号にする
5. 後の番号の仕事は、前の番号の仕事が main に統合されてから、その時点の main で worktree を作る
6. 触るか迷ったファイルは「触る」として扱う
7. 状態は 待ち → 作業中 → 受け入れ待ち → 統合済み → 片付け済み の順に書き換える

## 記入例（箇条書きで書く場合）

```markdown
- 順1：並び替えに逆順を足す（task/sort-reverse）
  - 触るファイル：src/sort.py、tests/test_sort.py
  - 重なり：src/sort.py
  - 始める条件：すぐ
  - 状態：作業中
- 順1：色を緑にする（task/theme-green）
  - 触るファイル：src/theme.py
  - 重なり：なし
  - 始める条件：すぐ
  - 状態：作業中
- 順2：並び替えに長さ順を足す（task/sort-length）
  - 触るファイル：src/sort.py、tests/test_sort.py
  - 重なり：src/sort.py
  - 始める条件：sort-reverse の統合後
  - 状態：待ち
```
