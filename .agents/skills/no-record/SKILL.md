# 要約を残す

確認用識別子: NO-RECORD

1. 保存するドメインを確認する。
2. 目的／決まったこと／根拠・読む資料／確認した結果／未確認／次の作業を短いMarkdownにまとめる。会話全文、秘密、非公開資料を入れない。
3. 要約案と保存先を本人へ示し、内容を確認してもらう。すでに保存指示があればその範囲で進める。
4. キットのルートから `scripts/no.py record --domain <domain> --name <記録名> --text <確認した要約>` をPythonで実行する。Macは `python3`、Windowsは `py -3` を前に付ける。本文を安全に渡せない場合はUTF-8の標準入力を使う。シェルの引用符内へ未確認の文字列をそのまま埋め込まない。
5. 保存したMarkdownを読み返す。該当ドメインのINDEX.mdにリンクを追加し、HANDOFF.mdを今の目的・決定・未確認・次の作業・読む記録に更新する。既存の必要な条件を消さない。
6. 保存した相対パス、確認結果、残件を報告する。

recordは新規作成だけ。同名なら別の記録名を使う。索引と引継ぎはAIまたは本人が手で編集し、CLIは自動更新しない。
